# C# Learning – Урок 1

## Что реализовано

- Консольный калькулятор, поддерживающий операции `+ - * / % ^`.
- Парсинг чисел в обычной и экспоненциальной (научной) форме.
- Вычисление цепочки операций слева‑направо без учёта приоритетов.
- Набор unit‑тестов (xUnit) для всех функций.

## Как запустить

```powershell
# Запуск самого калькулятора
dotnet run --project HelloWorld

# Запуск тестов
dotnet test HelloWorld.Tests
